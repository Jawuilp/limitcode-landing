# Prompt para pasar a Limitcode / OpenCode

Usa este prompt dentro del repositorio de la landing.

---

## Prompt

Quiero mejorar el posicionamiento comercial y SEO de la landing de Limitcode sin rehacer todo el sitio.

### Objetivo

Limitcode debe dejar de presentarse únicamente como “AI coding agent for Sublime Text” y comunicar claramente su diferenciación:

- lightweight;
- native Sublime integration;
- editor-first instead of terminal-first;
- BYOK;
- multi-provider;
- optional/non-intrusive;
- agentic workflow without moving to a heavy AI IDE.

### Importante

No inventes benchmarks ni números de RAM.

No hagas claims como:

- “uses 70% less RAM”;
- “faster than Claude Code”;
- “lighter than OpenCode”;

hasta que existan pruebas.

Sí puedes usar claims arquitectónicos y cualitativos como:

- built to keep the Sublime workflow lightweight;
- no separate AI IDE required;
- direct API providers do not require a separate agent daemon;
- stays out of the way when not in use.

### Cambios requeridos

1. Revisa el hero actual.
2. Mantén “AI coding agent for Sublime Text” visible por SEO.
3. Cambia el mensaje principal para enfatizar lightweight + native + stay in Sublime.
4. Añade una sección:
   “Why not just use Claude Code, Codex, Pi or OpenCode in a terminal?”
5. Explica que Limitcode no intenta reemplazar todos los workflows terminal-first.
6. Añade una sección “Built to stay lightweight”.
7. Añade una sección “More than a terminal embedded in Sublime”.
8. Revisa `/about/` o `/why-limitcode/` para explicar:
   - why Limitcode exists;
   - who it is for;
   - who it is not for.
9. Conserva el tono técnico, directo y no marketinero.
10. No elimines contenido SEO útil ya existente.
11. No rompas rutas, metadata, sitemap ni estructura de enlaces internos.
12. Reutiliza componentes existentes cuando sea posible.

### Copy recomendado

#### Hero H1

The lightweight AI coding agent for Sublime Text

#### Subheadline

Stay in Sublime. Edit projects, use multiple models, run tools, and work agentically without moving to a heavy AI IDE or adopting a terminal-first workflow.

#### Comparison intro

Terminal agents are excellent for terminal-first workflows. Limitcode is built for developers who want the agent to live where they already work: inside Sublime Text.

### Entregables

Antes de editar:

1. inspecciona la estructura actual del sitio;
2. enumera los archivos que modificarías;
3. explica brevemente qué cambiarías en cada uno.

Después:

1. aplica los cambios;
2. revisa responsive;
3. revisa metadata;
4. revisa links internos;
5. verifica que el sitemap/build siga funcionando;
6. resume los cambios finales.
