# Limitcode positioning pack

Este paquete reúne los cambios de posicionamiento, landing, SEO y artículos comparativos sugeridos a partir del feedback recibido durante el outreach.

## Objetivo principal

Reposicionar Limitcode no como “otro agente de IA para Sublime”, sino como:

> **A lightweight, native AI coding agent for developers who want to stay in Sublime Text.**

La diferenciación principal debería apoyarse en:

1. **Lightweight** — bajo overhead, sin convertir el entorno en un IDE pesado.
2. **Native Sublime integration** — contexto, archivos, selecciones, edición y sesiones dentro del editor.
3. **Editor-first, not terminal-first** — no obliga a adoptar un workflow basado en CLI.
4. **BYOK + multi-provider** — varios modelos/proveedores bajo una misma interfaz.
5. **Optional and non-intrusive** — si no se usa, prácticamente desaparece del workflow.
6. **Agentic workflow** — edición de proyecto, herramientas, MCP, skills, subagentes, web, etc.

## Archivos
